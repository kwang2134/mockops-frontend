# 랜딩 페이지 이미지 가이드 (업데이트 버전)

## 개요

랜딩 페이지 레이아웃을 교차 패턴으로 재구성하여 각 Feature 섹션당 1개의 큰 이미지를 사용합니다.

## 레이아웃 패턴

- **섹션 2**: 텍스트 좌(40%) / 이미지 우(60%)
- **섹션 3**: 이미지 좌(60%) / 텍스트 우(40%)
- **섹션 4**: 텍스트 좌(40%) / 이미지 우(60%)
- **섹션 5**: 이미지 좌(60%) / 텍스트 우(40%)

교차 패턴으로 시각적 흐름이 역동적입니다.

---

**위치:** 섹션 1 - Hero Section
**자동 전환:** 5초마다 페이드 효과로 전환
**투명도:** 30% (텍스트 가독성 확보)

#### Hero Background 1-3

- **대체 크기:** `2560x1080px` (21:9 초광각)

## 이미지 최적화 가이드

### 파일 형식 선택
- **JPG/JPEG**: Hero 배경 이미지 (복잡한 그라데이션)
- **PNG**: UI 스크린샷 (선명한 텍스트와 아이콘)
- **WebP**: 최신 브라우저 지원, 파일 크기 작음 (권장)

### 압축
- JPG: 80-85% 품질
- PNG: TinyPNG 또는 ImageOptim 사용
- WebP: Squoosh 사용 (75-80% 품질)

### 반응형 대응
- `@2x` 버전 준비 (레티나 디스플레이)
- 예: `feature-project-dashboard.png` → `feature-project-dashboard@2x.png` (2400x1600px)

## 변경 사항 (이전 버전 대비)

### 이미지 개수 감소
- 섹션당 2개씩 세로 배치 → 1개씩 큰 이미지로 통합
- 11개 → 7개로 간소화

### 레이아웃 개선
- 좌우 교차 패턴 (지그재그) 적용
- 이미지 비율: 16:10 → 3:2 (더 와이드한 느낌)
- 이미지 크기: 더 크고 임팩트 있게 (60% 차지)

### 디자인 요소 추가
- 각 섹션에 카테고리 태그 (Project Management, Mock API 등)
- 체크리스트 형태로 주요 기능 표시
- 더 깔끔하고 스캔하기 쉬운 레이아웃

## 이미지 촬영 가이드

실제 서비스 개발 완료 후 스크린샷 촬영 시:

1. **브라우저 해상도**: 1920x1080 이상으로 설정
2. **확대/축소**: 100% (기본 크기)
3. **UI 상태**: 데이터가 충분히 채워진 상태
4. **테마**: Light 모드 (가독성)
5. **촬영 도구**:
   - macOS: Cmd + Shift + 4
   - Windows: Snipping Tool 또는 Greenshot
   - Chrome DevTools의 Device Mode (정확한 크기)
