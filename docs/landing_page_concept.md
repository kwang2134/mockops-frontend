# 랜딩 페이지 구현 컨셉 (스크롤 스냅)

랜딩 페이지는 고정 헤더와 스크롤 스냅(Scroll-Snap) 기능을 활용한 몰입형 구조를 핵심으로 합니다.

### 1. 📋 페이지 구조 (Global Component)

#### 고정 헤더 (Fixed Header / Top Bar)

- **위치:** 화면 상단에 고정 (position: fixed).
  - **구성 요소:**
    - **좌측/중앙:** 서비스 로고 및 이름.
    - **우측 고정:** 로그인 버튼 (`Login` 또는 `시작하기`). (로그인 상태에 따라 사용자 프로필 또는 대시보드 링크로 전환됨)

### 2. 🖱️ 핵심 UX: 풀 페이지 스크롤 스냅 (Full-Page Scroll-Snap)

전체 컨텐츠 영역은 CSS의 `scroll-snap-type: y mandatory` 속성을 사용하여 구성됩니다. 사용자가 스크롤을 시도할 때, 브라우저가 다음 섹션의 시작점으로 화면을 자동으로 이동시켜 항상 전체 화면을 꽉 채우도록 만듭니다.

### 3. 🖼️ 랜딩 페이지 섹션 구성 (100vh Sections)

각 섹션은 뷰포트 높이(`100vh`)를 차지하며, 사용자는 마우스 휠이나 터치 스와이프를 통해 이 섹션들을 순차적으로 탐색하게 됩니다.

#### 섹션 1: 비주얼 임팩트 (Hero Section)

| 항목      | 설명                                    | 구현 목표 |
|---------|---------------------------------------|------------------------------------------------|
| **높이**  | 100vh (화면 전체 높이)                      | |
| **배경**  | **이미지 전환 효과 (Continuous Transition)** | 고품질 스틸컷/배경 이미지를 부드럽게 페이드-인/아웃(Fade-in/out) 또는 슬라이드 방식으로 계속 교체하여 시각적 몰입도를 극대화합니다. |
| **텍스트** | 서비스의 핵심 가치 슬로건 (중앙 배치)                | 예: "당신의 프로젝트를 위한 완벽한 Mocking 매니저." |
| **CTA 보조** | "Scroll Down" 또는 아래 방향 화살표 애니메이션 | 사용자에게 스크롤 가능한 페이지임을 알려줍니다. |
